## Formulario de registro de solicitudes.

### Incluye los campos:

Título (5-60 caracteres)

Descripción (20-500 caracteres)

Categoría

Prioridad (1-5)

Email (formato válido)

### Validaciones:

Longitud mínima y máxima en título y descripción.

Validación de email.

Rango de prioridad entre 1 y 5.

### Funcionamiento:

Botón deshabilitado durante el envío para evitar duplicados.

Mensaje de confirmación tras envío exitoso.

Manejo de errores con posibilidad de reintento sin pérdida de datos.

### Persistencia:

Almacenamiento automático en Webform submissions (es como si usara una base de datos local)

### Listado:

Vista "Mis solicitudes" ordenada por fecha de creación descendente.

Este formulario está diseñado para cumplir con los requisitos del ejercicio E2 (Formulario + BBDD).
